# Social Media Application (SMA)

## Overview

The Social Media Application (SMA) is a web-based platform that provides users with basic social networking functionality. Users can create accounts, log in, manage their profiles, share status updates, and communicate through an integrated messaging system.

The project was developed using HTML, CSS, JavaScript, PHP, and MySQL.

## Features

- **User Authentication:** Account registration and login functionality.
- **User Profiles:** Users can view and manage their profiles.
- **Status Updates:** Users can create and share updates.
- **Messaging System:** An inbox that allows users to communicate with one another.
- **Database Integration:** MySQL database for storing application and user information.

## Technologies Used

| Technology | Purpose                |

| CSS        | Styling and layout     |

## Getting Started

### Prerequisites

- A local PHP development environment (XAMPP recommended).
- MySQL database.
- A web browser.
- Git (optional).

### Installation

1. Clone or download this repository.
2. Place the project folder inside your local server's web directory (such as `htdocs` in XAMPP).
3. Start Apache and MySQL.
4. Create the required MySQL database.
5. Import the project's database SQL file, if provided.
6. Update the database connection settings in the PHP configuration file.
7. Open the application in your browser:

   `http://localhost/SMA`
